# RemoteCI AstrbotConnector

插件 ID：`astrbot_plugin_remoteci`

[AstrBot](https://github.com/AstrBotDevs/AstrBot) 插件：把 [RemoteCI](https://github.com/Edge-HH/RemoteCI) 接入 QQ、Telegram、飞书、钉钉、企业微信等聊天平台。

> [!WARNING]
> 开发中。需要 AstrBot ≥ 4.26（插件页面与插件 Web API 从该版本开始提供；更早版本只能使用聊天功能）。

## 功能

- **对话连接账号**：私聊发送 API Key 或用户名密码完成绑定，也可以直接用自然语言说。账号密码登录后只保存续期凭据，不保存密码；群聊中拒绝绑定。
- **RemoteCI Skill 的全部能力**：查课表、我的日程、下节课、教室状态；通知、换课、音量电源、扩展、集控广播；班级/分组/账号/成员/配对码/备份等系统管理。服务端按账号权限鉴权，高风险操作需要先确认。
- **指令 + 自然语言**：`/rci 帮助` 查看全部指令；其余操作直接用自然语言（LLM 工具 `remoteci_*`）。
- **自定义课程**：私聊说“每周三 14:00–14:45 双周加一节社团课”或“添加明天 14:00–15:00 的自习课，提前 20 分钟提醒，上课也提醒”，即可创建仅本人可见的每周课程（支持单双周、三/四周轮换，按管理员设置的学期开始日期计算）或单次课程；支持查询、修改、删除，与 RemoteCI 手机、手表、WebUI 同步。课程的课前/上课提醒按服务端逐课设置推送，不依赖换课权限，节假日照常提醒（管理员全局暂停推送仍生效）。
- **群聊只在 @ 机器人时处理**，且群聊不做个人主动提醒。
- **老师主动提醒**（个人私聊）：
  - 上学时推送当天个人日程（默认 07:00）；
  - 自己最后一节课下课时推送明天的个人日程（当天无课改用备用时刻，也可改为固定时间）；
  - 课前提醒（默认提前 10 分钟）；
  - 自己的课被换了提醒；
  - 班主任额外接收所管班级的课表变动（含任课教师变化）。
  - 老师可以用指令或自然语言开关每一项、修改当日/次日推送时间。
- **换课冲突确认**：通过换课申请时，如果有老师同一时间要在两个班上课等需要确认的冲突，机器人会列出冲突，确认后发送 `/rci 换课 确认通过 <编号>` 再通过；AI 对话中也会先问你再确认。班主任和系统管理员可用 `/rci 换课 撤回换课 <编号>` 撤回已生效的换课；换课失效（档案或调休变化后无法再套用）时会收到提醒。
- **换课快捷回复**（所有平台）：收到换课申请或强制换课的私聊提醒后，24 小时内直接回复“同意”“拒绝 理由”或“撤回”即可处理，不必输入 `/rci` 指令；待处理的不止一条时机器人会列出编号，回复“同意 编号”即可。只拦截 40 字以内、以这几个词开头的短消息，且服务端确认申请仍待处理时才生效，不影响普通聊天和自然语言对话。
- **原生卡片**（飞书、钉钉、企业微信）：换课申请（同意 / 拒绝 / 在 RemoteCI 中查看）、强制换课（撤回）、设备离线与恢复（查看设备状态）、自动化执行失败（查看规则）以卡片推送。审批按钮打开 RemoteCI 签发的一次性签名链接，在网页确认页上再确认一次；钉钉卡片另有“直接回复”按钮，点击即在聊天里发出快捷回复。其他平台（QQ、Telegram 等）推送文本 + 快捷回复提示 + 查看链接。卡片可在 WebUI 按平台关闭；服务端未提供签名链接接口、适配器不兼容或平台报错时自动改发文本。
- **运维群**：在 WebUI 把群设为“运维群”并选择一个管理员账号，群里会收到该账号的设备离线 / 恢复和自动化执行失败通知（与管理员私聊的推送各自记录进度，互不影响）。管理员私聊也会收到这些通知。
- **运维指令**：查看离线与待升级的教室设备、课时统计（管理员可查任意老师）、最近操作记录（管理员、班主任），列出 / 运行 / 开关自动化规则（管理员）。
- **班级群定时课表**：在 WebUI 把群设为“班级群”并显式开启后，按设定时间推送班级课表。
- **调休补课**：查看服务端的放假与调休安排（教室课表自动关闭 / 调休日自动开课），管理员可改某个调休上学日补哪天的课。
- **文件分发**：把文件发给机器人（或转发、回复那条文件消息），再说“帮我把这个文件发到高一3班桌面”或“发到我下一节课的班”，机器人经 RemoteCI 服务端中转，把文件发到教室电脑的桌面、下载或文档文件夹，并报告每台设备的接收进度；大文件在后台断点续传并校验完整性，没收完的完成后再私聊通知。也可以用 `/rci 发文件`。需要 RemoteCI“文件分发”权限（系统管理员默认拥有，老师等账号由管理员在角色配置或账号权限里开启）和支持中转分发的服务端与教室插件。
- **屏幕截图**：说“看看高一3班的屏幕”或用 `/rci 截图 高一3班`，机器人让教室电脑截取当前屏幕（含多显示器）并把图片直接发到聊天里，方便确认远程操作的效果。需要 RemoteCI“屏幕截图”权限（班主任默认拥有）和支持截图的服务端与教室插件；截图会写入操作记录。
- **服务端档案**：查看档案库，从教室电脑收集当前档案（含临时层），并把已保存的模板或班级档案下发到教室电脑，或只把某几天的临时层推下去（管理员或本班班主任）；档案内容在 RemoteCI WebUI 编辑。
- **节假日自动暂停**：法定节假日（含调休，数据来自 [holiday-cn](https://github.com/NateScarlet/holiday-cn)）、可选“周末视为假期”、自定义寒暑假区间。
- **内置 WebUI**（AstrBot 管理面板左侧“插件页面” → RemoteCI）：查看聊天身份与 RemoteCI 姓名的绑定关系，设置会话角色（老师 / 班主任 / 班级群 / 运维群），按平台开关原生卡片，统一提醒默认值，节假日，推送记录。界面沿用 AstrBot 管理面板的设计，深浅色跟随 AstrBot。

## 指令

```text
/rci 绑定 <API Key> [服务器]       /rci 登录 <用户名> <密码> [服务器]
/rci 我 | 解绑
/rci 今天 | 明天 | 本周 | 周三 | 10-05     我的日程
/rci 下节                                正在上和下一节
/rci 班级 [班级名] [日期]                  班级课表
/rci 状态 [班级名] | 班级列表 | 假期
/rci 提醒                                查看提醒设置
/rci 提醒 开|关 <当日|次日|课前|换课|班级换课|全部>
/rci 提醒 当日 07:30 | 次日 20:00 | 次日 下课 | 课前 15 | 重置
/rci 通知 <班级名> <内容>
/rci 发文件 <班级名…|下节课> [下载|文档] [覆盖]   发送本条、被回复或 30 分钟内刚发来的文件
/rci 截图 [班级名]   查看教室电脑当前屏幕，图片直接发到聊天
/rci 班级改名 [班级名] <新名称> | 班级头像 [班级名]（附带图片） | 班级头像 清除 [班级名]
/rci 调休 | 调休 <日期> <周一…周五|不补课|自动>
/rci 档案 | 档案 收集 [班级名…] [保存] | 档案 下发 <档案名> <更新|新建|临时层> [班级名…] [替换]
/rci 换课 待办 | 我的 | 通过|拒绝 <编号> [备注] | 确认通过 <编号> [备注] | 撤回 <编号> | 撤回换课 <编号> | 撤销 <编号>
/rci 设备                                离线与待升级的教室设备（管理员、班主任）
/rci 课时 [本月|上月|<开始> <结束>] [教师名]   课时统计；教师名仅管理员可用
/rci 审计 [班级名]                        最近 10 条操作记录（管理员、班主任）
/rci 自动化 | 自动化 运行|开|关 <规则名>      自动化规则（管理员）
/rci 守护 | 守护 开|关 | 守护 延时 <分钟>        ClassIsland 应用守护全局策略与最近事件（管理员）
```

收到换课提醒后，私聊里也可以直接回复：

```text
同意 [编号] [备注]      通过、批准 同义
拒绝 [编号] [理由]
撤回 [编号]            撤回别人对我的强制换课
```

`/rci` 也可以写成 `/课表`。

`/rci 课时` 默认统计本月 1 日到今天，日期格式为 `2026-10-01`，区间最长一年。`/rci 自动化 开|关` 会先读取完整规则再只修改启用状态。`/rci 守护` 只修改全局策略；单台设备的单独设置请在 WebUI“应用守护”页完成。应用守护自动恢复或恢复失败的通知与设备告警一样，会推送给管理员私聊和运维群。

班级改名和班级头像需要系统管理员，或系统管理员允许改名/改头像的本班班主任。头像取同一条消息里（或被回复消息里）的第一张图片；超过 256 KB 或不是 PNG/JPEG/WebP 时，安装了 Pillow 会自动裁成 256px 正方形并压缩。

## 配置

| 配置项 | 说明 | 默认 |
| --- | --- | --- |
| `default_server_url` | 默认 RemoteCI 服务器地址，填写后绑定时可省略 | 空 |
| `timezone` | 学校时区 | `Asia/Shanghai` |
| `poll_minutes` | 换课检查间隔（分钟） | `5` |
| `group_require_at` | 群聊仅在 @ 机器人时处理 | `true` |

## 原生卡片

| 平台 | 卡片 | 发送接口 |
| --- | --- | --- |
| 飞书（`lark`） | 消息卡片 JSON 2.0，按钮打开链接 | 适配器的 `lark_api.im.v1.message.acreate`（私聊 `open_id`，群 `chat_id`） |
| 钉钉（`dingtalk`） | `sampleActionCard` 系列，链接用 `dingtalk://dingtalkclient/page/link` 在钉钉内打开，“直接回复”用 `dtmd://dingtalkclient/sendMessage` | `/v1.0/robot/oToMessages/batchSend`（私聊）、`/v1.0/robot/groupMessages/send`（群），`robotCode` 为适配器的 `client_id` |
| 企业微信（`wecom`） | 应用消息 `template_card`（`text_notice`），`jump_list` 放同意、拒绝和查看链接 | 适配器 `client.post("message/send")`，`agentid` 取适配器配置或最近一次收到消息时的应用 ID；仅成员私聊，微信客服模式不支持 |

AstrBot 的这三个适配器都不转发卡片按钮回调，所以按钮只打开链接（或在钉钉里发出快捷回复），插件不修改适配器。签名链接由 `POST /api/me/action-links` 签发；服务端没有这个接口（返回 404）时，换课类通知改发文本，设备与自动化告警的卡片不受影响。

### 企业微信文本推送

AstrBot 的企业微信适配器在两种情况下不能主动发消息：应用（`wecom`）重启后要等成员再发一条消息才知道 `agentid`；智能机器人（`wecom_ai_bot`）长连接模式没配“消息推送 Webhook”时没有主动发送通道。插件因此直接调平台接口发文本：

- 应用：`message/send` 文本消息，`agentid` 取适配器配置、适配器当前值或插件记下的值（任一成员给应用发过消息后会保存到 `state.json`，重启后仍可用）；仅成员私聊。
- 智能机器人长连接：`aibot_send_msg`（单聊 userid / 群聊 chatid，`markdown` 格式）。HTTP 回调模式仍走 AstrBot 的消息推送 Webhook。

直接发送失败时再交给 AstrBot 的 `send_message`。

## 数据

保存在 `data/plugin_data/astrbot_plugin_remoteci/`：`state.json`（绑定、会话、设置、卡片开关、快捷回复待处理项、推送记录）、`snapshots.json`（换课比对基线）、`holiday-<年>.json`（节假日缓存）。凭据（API Key 或续期密钥）以明文保存在该目录，请保护好 AstrBot 数据目录。

## 开发

业务逻辑在 `remoteci/`，不依赖 AstrBot，可以直接测试：

```bash
pip install pytest aiohttp
python -m pytest -q
```

`remoteci/skill/` 是 RemoteCI 仓库 `skills/remoteci/` 的副本，供 `remoteci_reference` 工具读取；RemoteCI 新增功能时需要同步 API、Skill 和本插件。
